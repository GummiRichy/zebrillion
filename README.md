# 🦓 Zebrillion — the lecture dive

A rarity trivia game for med school lectures. Seven "name one thing" prompts, 25 seconds each.
Obvious answers float; rare-but-correct answers sink you deeper. 700 is the trench floor.

Mechanic inspired by [Krillion](https://krillion.io) — go play the original daily dive too.

## Play
Open the site, type a diver name, hit **BEGIN DESCENT**.

## Add a new lecture dive
1. Build it with the AI builder on the Claude version of Zebrillion (Build a dive → upload slides/transcript → Generate).
2. Press **COPY PACK CODE**.
3. Open `packs.txt` in this repo → ✏️ Edit → paste the code as **one new line** at the bottom → Commit changes.
4. The site updates in about a minute. Share `…/zebrillion/#dive-<id>` to link straight to that dive (the LINK button in the Library copies it).

Delete a line in `packs.txt` to remove a dive.
